# いろいろなデッキでの自動対戦（カードリスト v0.9）

勢力の組ごとに 40 個、合計 120 個のデッキを乱数で組み（どのカードも同じくらい入るように）、見本デッキ3つと先手・後手を入れ替えて 2 試合ずつ対戦した（ふつう同士、1440 試合）。この表はマリガンの表を v0.9 のカードで作り直す前に集計した。

- 使用率 = そのカードがデッキに入っていた試合のうち、使った試合の割合
- 強さ = 勝ち負けを、デッキに入っている枚数で説明する線形回帰（リッジ）の係数。1枚増やしたときの勝率の増減（ポイント）。相手のデッキの強さは別の項で取り除いている
- 使った試合の勝率は、勝っているときに使いやすいカード（重いカードなど）ほど高く出る

見立て:
- 強いデッキは、2コストの軽いユニット（ストリートサムライ・警備ドローン・双子騎士・王都の弓兵・巡回騎士）で序盤の盤面を取り、射撃（ゴーストハッカー・狙撃手ヴァイパー）と、盤面をまとめて削る・強化するカード（雷鳴の詠唱・鼓舞の号令）で押し切る形。
- 10コストのカード（ガラハド・オラクル・ゴーレム・ガンシップ）や、盤面に残らない高コストのスペル（ラグナロク・開戦・禁呪）は、出す前に勝負がつくことが多く、使用率も強さも低い。天空の大魔導師は使った試合の勝率が高いが、勝っている試合ほど10ラウンド目まで続きやすいためでもあり、出せる試合自体が少ない。
- 竜殺しの英雄は、戦闘で耐える回数が多い（ユニットを並べる）デッキでは強い。
