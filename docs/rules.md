## 1. 基本パラメータ（暫定値）

数値はすべて暫定値。バランス調整で変わる前提で、実装では定数として1か所にまとめる。

| パラメータ | 値 |
|---|---|
| 初期ライフ | 20 |
| デッキ枚数 | ちょうど40枚 |
| 同名カードの上限 | 3枚 |
| 初期手札 | 4枚 |
| 最大マナの上限 | 10 |
| 予備マナの上限 | その時点の最大マナと同じ |
| 手札の上限 | 10枚 |
| 盤面 | 4レーン × 前列・後列 = 1人8マス |
| リーダー能力の使用回数 | 各リーダーにつき1ラウンド1回 |

## 2. 用語

| 用語 | 意味 |
|---|---|
| プレイヤー | 対戦する2人。試遊版では一方が人間、もう一方がAI |
| 相手 | あるプレイヤーから見たもう一方のプレイヤー |
| ライフ | プレイヤーの体力。0以下になると敗北する |
| 山札 | デッキを裏向きにして置いたもの。上から引く |
| 手札 | 引いたカード。持ち主だけが中身を見られる |
| トラッシュ | 使い終わったスペルや、破壊されたユニットのカードを置く場所 |
| 盤面 | ユニットを置く場所。各プレイヤーが8マスずつ持つ |
| マス | 盤面の1区画。「レーン番号 + 列」で表す（例: 2前、3後） |
| レーン | 盤面の縦の並び。1〜4の番号があり、双方の同じ番号のレーンが向かい合う |
| 前列 / 後列 | 各レーンの2段。前列が相手側、後列が自分側 |
| リーダー | 各勢力の少年。盤面には出ず、リーダーゾーンにいる |
| リーダーゾーン | リーダー2人がいる場所。盤面の外 |
| 通常マナ | カードを使うためのマナ。毎ラウンド全回復する |
| 最大マナ | 通常マナが全回復したときの値。ラウンドごとに1ずつ増える |
| 予備マナ | 使い残した通常マナが貯まったもの。リーダー能力と追加能力にのみ使える |
| 先手トークン | そのラウンドで最初に行動するプレイヤーを示す目印 |
| 行動権 | 今アクションを行えるプレイヤーを示す権利。手番が終わると相手へ移る |
| 手番 | 行動権を得てから相手に渡すまでの間。1回の手番で行うアクションは1つ。即効を使うと、手番が終わった後に追加の手番を得る（6.2） |
| アクション | 行動権を持つプレイヤーが1回に行う行動（7章） |
| ユニット | 盤面に置くカード、およびトークン。攻撃力と体力を持つ |
| トークン | カードの効果で盤面に出るユニット。デッキには入らない |
| スペル | 使うと効果を発揮してトラッシュに置かれるカード |
| 効果 | カードやリーダーに書かれた処理 |
| キーワード | よく使う効果に付けた名前（14章） |
| 追加能力 | カードに付いた、予備マナ（または通常マナ）を払って使う効果。「強化」と「起動」がある（15章） |
| リーダー能力 | リーダーが持つ、予備マナ（または通常マナ）を払って使う効果 |
| 成長 | リーダーが成長条件を満たして強化されること。段階は「通常」と「成長」の2つ |
| 遅延 | 使ったときに予約し、自分の次の手番の始めに発動する効果。発動がその手番のアクションになる（14.1） |
| 即効 | 使った後、相手に行動権を渡さずに **追加の手番** を得るキーワード（14.2） |
| 遅延ゾーン | 予約中の遅延効果を持つカードを置く場所 |

## 3. 準備

### 3.1 デッキの条件

デッキは次の条件をすべて満たす必要がある。満たさないデッキでは対戦できない。

1. **リーダーを2人** 選ぶ。2人は **異なる勢力** のリーダーでなければならない。
2. デッキは **ちょうど40枚**。
3. デッキのカードはすべて、選んだ2人のリーダーのどちらかの勢力に属するカードか、**中立カード** でなければならない。
   - 2勢力と中立の枚数の比率に制限はない。一方の勢力のカードだけで40枚にしてもよい（40:0）。その場合でも、リーダーは異なる勢力から2人選ぶ。
   - **中立カード**: どの勢力にも属さず、どのデッキにも入れられるカード。
4. 同じ名前のカードは **3枚まで**。
5. トークンはデッキに入れられない。

### 3.2 対戦開始の手順

1. 双方のライフを20にする。
2. 双方のリーダー2人をリーダーゾーンに置く。どちらも「通常」の段階で、成長条件の進み具合は0。
3. 双方の最大マナ・通常マナ・予備マナを0にする。
4. 双方がデッキをシャッフルして山札にする。
5. 第1ラウンドの先手トークンを持つプレイヤーを **ランダムに決める**。
6. 双方が山札から4枚引く。
7. **マリガン**（引き直し）を行う（3.3）。
8. 第1ラウンドを始める（6章）。

### 3.3 マリガン

- 双方が同時に、手札から戻したいカードを0〜4枚選ぶ。相手が何枚選んだかは、選び終わるまで分からない。
- 選んだカードを脇に置き、同じ枚数を山札から引く。その後、脇に置いたカードを山札に戻してシャッフルする。
  - この順番なので、戻したカードを同じマリガンで引き直すことはない。
- マリガンは1回だけ。

## 4. ゾーンと公開情報

| ゾーン | 中身 | 相手から見えるもの |
|---|---|---|
| 山札 | 裏向きのカード | 枚数のみ |
| 手札 | 引いたカード | 枚数のみ |
| 盤面 | 置かれたユニット | すべて（能力値、受けているダメージ、付いている効果） |
| トラッシュ | 使い終わったカード | すべて |
| リーダーゾーン | リーダー2人 | すべて（段階、成長条件の進み具合、今ラウンドに能力を使ったか） |
| 遅延ゾーン | 予約中の遅延効果を持つカード | すべて（カードの内容、指定した対象、強化したか） |

- ライフ、最大マナ、通常マナ、予備マナは双方に公開される。
- AIは人間と同じく、ここで「相手から見える」とされた情報だけを使って判断する。山札の順番や相手の手札の中身を参照してはならない。

## 5. 盤面とマス

### 5.1 マスの表し方

```
            レーン1   レーン2   レーン3   レーン4
          ┌───────┬───────┬───────┬───────┐
 相手 後列 │ 1後   │ 2後   │ 3後   │ 4後   │
          ├───────┼───────┼───────┼───────┤
 相手 前列 │ 1前   │ 2前   │ 3前   │ 4前   │
          ╞═══════╪═══════╪═══════╪═══════╡  ← 戦線
 自分 前列 │ 1前   │ 2前   │ 3前   │ 4前   │
          ├───────┼───────┼───────┼───────┤
 自分 後列 │ 1後   │ 2後   │ 3後   │ 4後   │
          └───────┴───────┴───────┴───────┘
```

- レーン番号は **双方から見て同じ**（自分のレーン1の正面は相手のレーン1）。
- 1マスにユニットは1体まで。ユニットがいないマスを「空きマス」と呼ぶ。

### 5.2 位置関係

| 用語 | 意味 |
|---|---|
| 同じレーン | レーン番号が同じマス |
| 左右隣 | 同じ列で、レーン番号が1違うマス（レーン1と4は隣ではない） |
| 前後隣 | 同じレーンの、もう一方の列のマス |
| 隣 | 左右隣と前後隣をまとめた呼び方。斜めは含まない |
| 正面 | 自分のマスと同じレーンにある、相手の前列のマス |

### 5.3 盤面の順番

効果の処理順などで「盤面の順番」と言ったときは、次の順番とする。

**1前 → 1後 → 2前 → 2後 → 3前 → 3後 → 4前 → 4後**

## 6. ラウンドの進行

ゲームは「ラウンド」を繰り返して進む。1ラウンドは4つのフェイズでできている。

```
開始フェイズ → 行動フェイズ → 戦闘フェイズ → 終了フェイズ
```

### 6.1 開始フェイズ

次の順番で処理する。各手順は双方同時に行う。

1. ラウンド数を1増やす。
2. **最大マナ** を1増やす（10を超えない）。
3. **予備マナの加算**: 前のラウンドの終了時に記録した「使い残した通常マナ」（6.4）を予備マナに加える。加えた結果が最大マナを超える場合は、最大マナと同じ値にする（超えた分は消える）。第1ラウンドでは加算する値は0。
4. **通常マナ** を最大マナと同じ値にする（全回復）。
5. **ドロー**: 双方が山札から1枚引く。
   - 山札が0枚で引けないプレイヤーは敗北する（9章）。
   - 手札が上限（10枚）のときに引いたカードは、手札に加えずトラッシュに置く。
6. **先手トークン**: 第1ラウンドは3.2で決めたプレイヤーが持つ。第2ラウンド以降は、前のラウンドで持っていなかったプレイヤーに移る。
7. 1ラウンドに回数制限のある使用記録（リーダー能力、起動、機動）をリセットする。
8. 「ラウンド開始時」の効果を処理する（11章の順番で）。

### 6.2 行動フェイズ

1. 先手トークンを持つプレイヤーが **行動権** を得て、手番を始める。
2. **手番の始めに、そのプレイヤーの予約中の遅延効果が発動できる状態なら、必ず発動する**（14.1）。これがその手番のアクションになる。
3. そうでなければ、行動権を持つプレイヤーはアクションを1つ行う（7章）。パスもアクションの1つ。
4. アクションとその結果（誘発した効果を含む）をすべて処理し終えたら手番が終わり、行動権は相手に移る。
   - ただし **即効** を持つカード・能力を使った場合は、手番が終わった後、行動権を相手に渡さずに **追加の手番** を得る（14.2）。追加の手番も通常の手番と同じく、始めに遅延効果の発動を確認する。
5. **双方が続けてパスした** ら、行動フェイズを終えて戦闘フェイズに進む。
   - 「続けて」とは、一方がパスし、その直後の相手のアクションもパスであること。
   - 一方がパスしても、相手がパス以外のアクションを行えば、行動権は戻ってきて再びアクションを行える。
   - **予約中の遅延効果が残っている間は、行動フェイズは終わらない**。双方が続けてパスしても、遅延効果を持つプレイヤーの手番になり、遅延効果が発動する。

**例**: A（先手）ユニット配置 → B パス → A スペル → B ユニット配置 → A パス → B パス → 戦闘フェイズへ

### 6.3 戦闘フェイズ

8章の手順で、全レーンの戦闘を同時に解決する。

### 6.4 終了フェイズ

1. 「ラウンド終了時」の効果を処理する（11章の順番で）。
2. 「このラウンド中」と書かれた効果が終わる。
3. 双方の **使い残した通常マナ**（この時点の通常マナの値）を記録する。この値が次のラウンドの開始フェイズで予備マナに加わる。
4. 次のラウンドの開始フェイズへ。

## 7. アクション

行動権を持つプレイヤーは、次のうち1つを行う。

| アクション | コスト | 回数制限 |
|---|---|---|
| ユニット配置 | 通常マナ（カードのコスト）＋ 強化するなら追加コスト | なし |
| スペル使用 | 通常マナ（カードのコスト）＋ 強化するなら追加コスト | なし |
| 前進 | なし | なし |
| リーダー能力の使用 | 予備マナ／通常マナ（能力のコスト） | 各リーダーにつき1ラウンド1回 |
| 起動能力の使用 | 予備マナ／通常マナ（能力のコスト） | 各ユニットの各起動能力につき1ラウンド1回 |
| 機動による移動 | なし | 各ユニットにつき1ラウンド1回 |
| パス | なし | なし |
| （遅延効果の発動） | なし（予約時に支払い済み） | 手番の始めに自動で行う。選べるアクションではない（14.1） |

- 条件を満たさないアクションは行えない（例: マナが足りない、置ける空きマスがない、対象がいない）。
- どのアクションも行えない場合でも、パスは必ず行える。

### 7.1 ユニット配置

1. 手札からユニットカードを1枚選ぶ。
2. 置くマスを選ぶ。自分の空きマスで、カードの配置制限（「前列のみ」「後列のみ」）を満たすマスでなければならない。
3. 強化するかどうかを決める（15章）。
4. コストを支払う。
5. ユニットを選んだマスに置く。
6. 「配置時」の効果を処理する。効果に対象が必要な場合は、ここで対象を選ぶ。対象がいなければ、その効果は何もしない。

- 配置したラウンドから攻撃に参加する（配置したばかりで攻撃できない、という制限はない）。

### 7.2 スペル使用

1. 手札からスペルカードを1枚選ぶ。
2. 対象が必要なスペルは対象を選ぶ。**必要な対象を選べない場合、そのスペルは使えない。**
3. 強化するかどうかを決める（15章）。
4. コストを支払う。
5. 効果を処理する。
6. スペルカードをトラッシュに置く。遅延効果を予約したスペルは、トラッシュではなく遅延ゾーンに置く（14.1）。
7. 「スペル使用時」の効果を処理する。

### 7.3 前進

- 自分の **後列** にいるユニット1体を、**同じレーンの前列** に動かす。
- 同じレーンの前列が空きマスでなければ行えない。
- コストは不要。1回の前進で1アクションを使う。1ラウンドに何回でも行える（1回ごとに行動権は相手に移る）。
- 前進は「移動」の一種として扱う（12章）。

### 7.4 リーダー能力の使用

- 自分のリーダー1人を選び、その能力を使う。
- そのリーダーが今ラウンドすでに能力を使っていれば行えない。
- コストの支払い方は16.2を参照。

### 7.5 起動能力の使用

- 盤面にいる自分のユニットの起動能力を1つ選んで使う（15.2）。

### 7.6 機動による移動

- 「機動」を持つ自分のユニットを、自分の盤面の任意の空きマスへ動かす（14章）。

### 7.7 パス

- 何もしない。手番が終わり、行動権が相手に移る。

## 8. 戦闘の解決

戦闘フェイズでは、次の手順で全レーンの戦闘を同時に解決する。

### 8.1 手順

1. 「戦闘開始時」の効果を処理する。
2. **先制ステップ**: 「先制」を持つユニットだけで 8.2〜8.4 を行う。先制を持つユニットがいなければ飛ばす。
3. **通常ステップ**: 先制ステップで攻撃しなかったユニットで 8.2〜8.4 を行う。
   - 先制ステップで破壊されたユニットは攻撃しない。
   - 攻撃対象は、先制ステップが終わった後の盤面で決め直す。
4. 「戦闘終了時」の効果を処理する。

### 8.2 攻撃するユニットを決める

次のユニットが攻撃する。

- 前列にいて、攻撃力が1以上のユニット
- 後列にいて、「射撃」を持ち、攻撃力が1以上のユニット

攻撃力0のユニットは攻撃しない。後列にいて射撃を持たないユニットは攻撃しない。

### 8.3 攻撃対象を決める

攻撃するユニットごとに、**同じレーンの相手側** を次の順番で見て、最初に見つかったものを対象にする。

1. 相手の前列のユニット
2. 相手の後列のユニット
3. 相手本体（ライフ）

- 対象は、そのステップの開始時点の盤面で決める。ステップ中にダメージで体力が0以下になっても、対象は変わらない。
- 前列のユニットと射撃を持つ後列のユニットは、同じ順番で対象を決める。したがって同じレーンでは、自分の前列と後列が同じ対象を攻撃することがある。

### 8.4 ダメージを与える

1. 攻撃するユニットはすべて、対象に **自分の攻撃力と同じダメージ** を与える。
2. ダメージは **すべて同時** に与える。あるユニットが先に破壊されたから攻撃できなくなる、ということはない。
3. 攻撃されたユニットが反撃するわけではない。前列同士が互いにダメージを与え合うのは、双方がそれぞれ正面の相手を攻撃しているからである。
4. ダメージを与え終わったら、体力が0以下になったユニットをすべて同時に破壊する（10.3）。
5. ライフの勝敗判定を行う（9章）。敗者が決まれば、ゲームはその時点で終わる。

**貫通のダメージ**: 「貫通」を持つユニットのダメージが対象のユニットの残り体力を超えた場合、超えた分を同じレーンの次の対象（相手の後列 → 相手本体）に与える（14章）。同じレーンの同じ側から複数のユニットが同じ対象を攻撃する場合、残り体力は **前列のユニット → 後列のユニット** の順に割り当てて計算する。

## 9. 勝敗

### 9.1 敗北条件

- **ライフが0以下** になったプレイヤーは敗北する。
- **ドローするときに山札が0枚** のプレイヤーは敗北する。

### 9.2 判定のタイミング

勝敗は次のタイミングで判定する。

- 各アクションの処理が終わったとき（誘発した効果の処理も含めて終わったとき）
- 戦闘の各ステップでダメージを与え終わったとき
- 開始フェイズのドローを終えたとき
- 各フェイズの効果の処理が終わったとき

### 9.3 双方が同時に敗北条件を満たした場合

- **双方のライフが同時に0以下** になった場合、**ライフのマイナスが大きい側が負け**。
  - 例: Aが −3、Bが −1 → Aの負け。
  - 例: Aが 0、Bが −2 → Bの負け。
  - 値がまったく同じ場合（例: 双方 −2、双方 0）は **引き分け**。
- **双方の山札が同時に尽きた** 場合（開始フェイズのドローで双方とも引けない）は **引き分け**。
- 一方がライフ0以下、もう一方が山札切れで同時に敗北条件を満たすことは、判定のタイミング上起こらない（山札切れは開始フェイズでしか起こらず、そこでライフは変化しないため）。ただし将来、ドローさせる効果を追加する場合は判定方法を決め直す。

## 10. ユニット

### 10.1 能力値

- ユニットは **攻撃力** と **体力** を持つ。「3/4」は攻撃力3・体力4を表す。
- 体力には「最大体力」と「受けているダメージ」があり、**残り体力 = 最大体力 − 受けているダメージ**。
- 攻撃力が0未満になる場合は0として扱う。

### 10.2 ダメージと回復

- ダメージを受けると、受けているダメージが増える。
- **受けたダメージはラウンドをまたいで残る**（ラウンドの終わりに自動で回復しない）。
- 「回復」は受けているダメージを減らす。0未満にはならない。
- 「+X/+Y」の強化は、攻撃力をX、最大体力をY増やす（残り体力もY増える）。
- 「−X/−Y」の弱体化で最大体力が下がり、残り体力が0以下になったユニットは破壊される。

### 10.3 破壊

- 残り体力が0以下になったユニットは破壊される。破壊の判定はダメージや弱体化を処理し終えた時点でまとめて行い、該当するユニットを **同時に** 破壊する。
- 破壊されたユニットのカードは持ち主のトラッシュに置く。トークンは消える。
- 「破壊時」の効果は、ユニットが盤面から取り除かれた後に処理する（11章の順番で）。

---

## 11. 効果の処理

### 11.1 基本

- 効果はすべて **即時に解決する**。相手が割り込んで対応することはできない。
- 1枚のカードに複数の効果がある場合は、書かれている順番に処理する。

### 11.2 誘発する効果

条件を満たしたときに自動で起こる効果を「誘発効果」と呼ぶ。試遊版で使う誘発のタイミングは次のとおり。

| タイミング | 起こるとき |
|---|---|
| 配置時 | そのユニットを配置したとき |
| 破壊時 | そのユニットが破壊されたとき |
| 移動時 | そのユニットが移動したとき（前進を含む） |
| スペル使用時 | 自分がスペルを使ったとき（そのスペルの効果を処理し終えた後） |
| ラウンド開始時 | 開始フェイズの手順8 |
| 戦闘開始時 | 戦闘フェイズの手順1 |
| 戦闘終了時 | 戦闘フェイズの手順4 |
| ラウンド終了時 | 終了フェイズの手順1 |

### 11.3 同時に誘発した効果の順番

複数の誘発効果が同時に起きた場合は、次の順番で1つずつ処理する。

1. **そのラウンドの先手トークンを持つプレイヤー** の効果を先に、相手の効果を後に処理する。
2. 同じプレイヤーの効果は、**盤面の順番**（5.3）→ リーダーゾーン（1人目 → 2人目）の順に処理する。
   - 破壊時の効果は、破壊される直前にいたマスで順番を決める。

処理中に新しい誘発効果が起きた場合は、今の順番待ちの列の **最後に** 加える。

### 11.4 対象

- 「対象を選ぶ」と書かれた効果は、処理するときに対象を選ぶ。
- 選べる対象がない場合、スペルは使えない（7.2）。ユニットの配置時効果やリーダー能力の一部である場合、その効果は何もしない。
- 「ランダムに」と書かれた効果は、シード付きの乱数で決める（実装メモ参照）。

## 12. 移動

- 一度置いたユニットは、基本的に移動しない。移動できるのは次の場合だけ。
  - 前進（7.3）
  - 機動（14章）
  - 移動させる効果（スペル、リーダー能力など）
- **移動先は必ず空きマス**。移動先の条件を満たす空きマスがない場合、移動は起こらない。
- ユニットは相手の盤面へは移動しない。相手のユニットを移動させる効果も、移動先は相手自身の盤面のマスになる。
- 移動したユニットは、受けているダメージや付いている効果をそのまま持ち続ける。
- 移動は配置ではない。「配置時」の効果は起きない。
- 配置制限（「前列のみ」「後列のみ」）は、配置するときだけの制限で、移動には影響しない。

---

## 13. リーダー

### 13.1 基本

- リーダーは常にリーダーゾーンにいる。盤面には出ず、攻撃することも、攻撃・ダメージ・効果の対象になることもない。
- 各リーダーは次のものを持つ。
  - **リーダー能力**（通常の段階と成長後の段階の2種類）
  - **成長条件**

### 13.2 リーダー能力

- 行動フェイズのアクションとして使う（7.4）。
- 各リーダーにつき **1ラウンド1回まで**。1人のデッキには2人のリーダーがいるので、1ラウンドに最大2回使える。
- コストは予備マナ・通常マナのどちらでも、組み合わせても支払える（16.2）。

### 13.3 成長

- 成長条件の進み具合は、試合開始時から数え始める。
- 成長条件を満たしたら、その原因になった処理が終わった直後に **成長** する（「通常」→「成長」）。
- 成長すると、リーダー能力が成長後のものに置き換わる。
- そのラウンドにすでにリーダー能力を使っていた場合、成長しても使用済みのまま（同じラウンドにもう1回使えるようにはならない）。
- 成長は試合終了まで続く。成長の段階はこの2段階だけで、それ以上は成長しない。

## 14. キーワード能力（試遊版）

試遊版で使うキーワードは次のとおり。

| キーワード | 定義 |
|---|---|
| 射撃 | 後列にいても攻撃する（8.2）。攻撃対象の決め方は前列のユニットと同じ（8.3） |
| 貫通 | 戦闘で、対象のユニットの残り体力を超えたダメージを、同じレーンの次の対象（相手の後列のユニット、いなければ相手本体）に与える。超えたダメージの計算には盾を考慮しない（盾で防がれた場合、貫通するダメージもない） |
| 先制 | 戦闘の先制ステップで攻撃する（8.1）。通常ステップでは攻撃しない |
| 盾 | 次にこのユニットが受けるダメージを1回だけ0にする。0にしたら盾はなくなる。1体のユニットが持てる盾は1つまで（重ねても1つ） |
| 機動 | アクションとして、このユニットを **自分の盤面の任意の空きマス** へ移動できる（隣でなくてもよい）。各ユニットにつき1ラウンド1回 |
| 遅延 | 「遅延:」と書かれた効果は、使ったときには発動せず予約され、自分の次の手番の始めに発動する。発動はその手番のアクションになる。詳細は14.1 |
| 即効 | このカード・能力を使った後、行動権を相手に渡さずに追加の手番を得る。詳細は14.2 |

**「1回のダメージ」の数え方**: 戦闘では、攻撃する1体のユニットが与えるダメージを1回と数える。貫通で次の対象に与えるダメージは、次の対象にとっての1回と数える。効果では、1つの効果が1体に与えるダメージを1回と数える。

**試遊版では使わないキーワード（将来の候補）**: 挑発、巨体、押し出し。試遊版の後で必要に応じて定義する。

### 14.1 遅延

使ってから発動するまでに、**通常は相手に1回だけ手番を与える** キーワード。相手は予告された効果を見て、移動・守るスペル・強化などで対策できる。カード（ユニット・スペル）にも、起動能力やリーダー能力にも付けられる一般的なキーワードとして扱う。

**書き方**

```
崩落の予言（スペル・3）
マスを1つ指定する。
遅延: 指定したマスにいるユニットを破壊する。
```

```
狙撃の構え（スペル・2）
敵ユニット1体を対象にする。
遅延: 対象に4ダメージ。
```

- 「遅延:」が付いていない効果は、使ったときに通常どおり処理する。
- 「遅延:」が付いた効果は、使ったときには発動せず **予約** される。

**予約（使ったとき）**

1. コストと、強化するならその追加コストを支払う。マナはこの時点で支払い、発動時には支払わない。
2. 遅延効果の対象を選ぶ。対象は、カードに書かれたもの（ユニット、マス、レーン、プレイヤーなど）であれば何でもよい。
   - **マスやレーンを指定する効果**: 発動するときに、そこに **その時点でいるユニット** に作用する。移動で避けられる。
   - **ユニットを対象にする効果**: 対象のユニットが移動しても、そのユニットを追いかけて作用する。守るスペルや盾、体力の強化などで耐える形で対策する。
3. 「遅延:」が付いていない効果を処理する。
4. スペルの場合、カードを遅延ゾーンに置く。ユニット・起動能力・リーダー能力の場合、カードは元の場所に残り、予約だけが遅延ゾーンに記録される。
5. 予約の内容（カード、対象、強化したか）は双方に公開される。UIでは対象の上に予告の印を表示する。
6. 手番が終わり、行動権が相手に移る（即効も持つ場合は追加の手番を得る。14.2）。

**発動（自分の次の手番）**

- 予約したプレイヤーの **次の手番の始め** に、遅延効果が自動で発動する。これがその手番のアクションになり、発動を処理し終えたら手番が終わって行動権が相手に移る。
  - 発動は自分の行動として扱うので、「パス」ではない（双方が続けてパスした、の判定をリセットする）。
- 通常、相手は予約から発動までの間に **1回の手番** を行える。相手がその手番で即効を使えば追加の手番を得るので、発動までに複数のアクションを行える。
- 発動を選ばない・遅らせることはできない。予約した遅延効果は取り消せない。
- 発動時に対象がいなくなっている（ユニットが破壊された・盤面を離れた）場合、その対象に作用する部分は何もしない。マスやレーンを指定した効果で、そこにユニットがいなければ何もしない。
- 発動し終えたら、スペルのカードは遅延ゾーンからトラッシュに置く。
- 発動の後に勝敗判定を行う（9章）。

**「次の手番」の決まり方**

- 遅延効果は、予約した後の **自分の次の手番の始め** に発動する。その手番が相手の手番を挟んで来たものか、即効で得た追加の手番かは問わない。
  - そのため、**即効と遅延を両方持つカードは、即効で得た追加の手番の始めに遅延効果が発動し、その手番を使い切る**。結果として、相手に対策の機会を与えないかわりに、即効で得をすることもない（実質的に相殺する）。
- 1回の手番で行えるアクションは1つで、遅延効果の発動がその手番のアクションになるため、通常は予約中の遅延効果は同時に1つまでしか存在しない。
  - 何らかの効果で予約中の遅延効果が複数になった場合は、次の手番の始めに **予約した順にすべて発動** し、まとめて1回のアクションとして扱う【仮】。
- 予約中の遅延効果が残っている間は、行動フェイズは終わらない（6.2）。

**ユニット・能力の遅延効果**

- ユニットの配置時効果・起動能力・リーダー能力に遅延が付いている場合も、予約は元のユニットから独立する。予約した後で元のユニットが破壊・移動しても、遅延効果は発動する。

**相手の対策の例**

| 予約された効果 | 対策の例 |
|---|---|
| マスを指定する効果 | 機動・移動させるスペルで逃がす。後列のマスなら、前列が空いていれば前進で逃がす |
| ユニットを対象にする効果 | 盾を与える、体力を上げる、ダメージを防ぐスペルを使う |
| 本体へのダメージ | 本体を守る効果、ライフの回復 |
| どれでも | 発動前に勝負を決める、あえて安いユニットを差し出す |

**例（手番の流れ）**

```
A: 崩落の予言（マス 2前 を指定）          ← 予約。Aの手番終わり
B: 機動で 2前 のユニットを 4後 へ移動     ← Bの1回の手番
A: （手番の始めに遅延効果が発動）2前 は空きマスなので何もしない  ← Aのアクション
B: 次のアクション
```

**実装メモ**: 予約中の遅延効果（カード、持ち主、対象、強化したか、予約した順番、予約後に相手が行動したか）はゲームの状態に含める。AIは相手の予約を公開情報として評価に使う。

### 14.2 即効

- 即効を持つカード・能力を使い、その処理（誘発した効果を含む）を終えたら手番が終わる。その後、行動権を相手に渡さずに、同じプレイヤーが **追加の手番** を得る。
- 追加の手番は通常の手番と同じ扱いで、始めに遅延効果の発動を確認し（14.1）、その後アクションを1つ行う。パスもできる。
- 追加の手番で再び即効を使えば、さらに追加の手番を得る。
- 即効を持つカード・能力を使ったことは、パス以外のアクションとして「双方が続けてパスした」の判定をリセットする。
- **即効と遅延の両方を持つ場合**: 予約した後の追加の手番の始めに遅延効果が発動し、その手番を使い切る（14.1）。

**例1（即効）**

```
A: 即効スペル「応急手当」を使う            ← Aの手番終わり。Aが追加の手番を得る
A: ユニットを配置する                      ← Aの追加の手番。終わると行動権はBへ
B: 次のアクション
```

**例2（即効と遅延を両方持つカード）**

```
A: 即効・遅延を持つ「早口の火球」を使う（対象を予約）  ← Aの手番終わり。Aが追加の手番を得る
A: （追加の手番の始めに遅延効果が発動）              ← Aの追加の手番のアクション。終わると行動権はBへ
B: 次のアクション
```

## 15. 追加能力

追加能力のコストは、予備マナ・通常マナのどちらでも、組み合わせても支払える（16.2）。

### 15.1 強化

- 「強化（X）: 〇〇」と書かれたカードは、プレイするときに追加でXを支払うと、〇〇の効果が加わる。
- 強化するかどうかは、プレイするときに決める。後から強化することはできない。
- カード本体のコストは通常マナで、強化のコストは予備マナ／通常マナで支払う。

**例**: 「火球（3）: ユニット1体に3ダメージ。強化（2）: さらに、その対象と同じレーンの後列のユニットに2ダメージ」を強化して使う場合、通常マナ3と、予備マナ／通常マナ2を支払う。

### 15.2 起動

- 「起動（X）: 〇〇」と書かれたユニットは、盤面にいる間、アクションとしてXを支払って〇〇の効果を使える。
- 各ユニットの各起動能力は、1ラウンド1回まで。

## 16. マナ

### 16.1 値の変わり方

| タイミング | 最大マナ | 通常マナ | 予備マナ |
|---|---|---|---|
| 対戦開始時 | 0 | 0 | 0 |
| 開始フェイズ 手順2 | +1（上限10） | — | — |
| 開始フェイズ 手順3 | — | — | 前ラウンドの使い残しを加算（上限＝最大マナ） |
| 開始フェイズ 手順4 | — | 最大マナと同じ値にする | — |
| 行動フェイズ | — | 支払いで減る | 支払いで減る |
| 終了フェイズ 手順3 | — | 残りを「使い残し」として記録 | — |

### 16.2 支払い

- **カードのコスト**（ユニット配置・スペル使用）は、**通常マナでしか支払えない**。
- **リーダー能力・強化・起動のコスト** は、予備マナと通常マナを **自由に組み合わせて** 支払える。
  - UIでは初期設定として予備マナから先に使い、足りない分を通常マナで払う。プレイヤーは内訳を変更できる。
  - AIは内訳も含めて行動を選ぶ（通常マナを残すと、次のラウンドの予備マナになるため）。
- 1つのアクションで両方の種類のコストがある場合（強化してカードをプレイするとき）、カード本体の分は通常マナで、強化の分は予備マナ／通常マナで支払う。合計を支払えなければ、そのアクションは行えない。

### 16.3 例

| ラウンド | 最大マナ | 開始時の予備マナ | そのラウンドの使い方 | 使い残し |
|---|---|---|---|---|
| 1 | 1 | 0 | 何も使わない | 1 |
| 2 | 2 | 0＋1 = 1 | 2マナのユニットを配置 | 0 |
| 3 | 3 | 1＋0 = 1 | リーダー能力（コスト2）を予備1＋通常1で使う | 2 |
| 4 | 4 | 0＋2 = 2 | 何も使わない | 4 |
| 5 | 5 | 2＋4 = 6 → 上限5 | — | — |

## 17. 総合例（1レーン分の戦闘）

**盤面（レーン3）**

```
 B 後列 : 狙撃ドローン 2/2 [射撃]
 B 前列 : 鉄壁の門番 1/5 [盾]
 A 前列 : 突撃騎兵 4/3 [貫通]
 A 後列 : 弩兵 2/1 [射撃][先制]
```

**先制ステップ**
- 攻撃するのは A の弩兵だけ。対象は同じレーンの B の前列 → 門番。
- 門番の盾が2ダメージを0にし、盾がなくなる。破壊されるユニットはなし。

**通常ステップ**（対象を決め直す）
- A の突撃騎兵 → B の門番に4ダメージ。門番の残り体力は5なので超えた分はなく、貫通は起きない。
- B の門番 → A の突撃騎兵に1ダメージ。
- B の狙撃ドローン（射撃）→ A の前列の突撃騎兵に2ダメージ。
- 弩兵は先制ステップで攻撃したので、通常ステップでは攻撃しない。

**結果**
- 門番: 最大体力5、受けたダメージ4 → 1/5（残り1）で生き残る。盾はなくなった。
- 突撃騎兵: 受けたダメージ1＋2＝3 → 残り0で破壊される。
- 本体へのダメージはなし。
- 次のラウンドでは、A は後列の弩兵を前進させて前列の穴を埋めることができる。

## 18. 実装メモ

- **状態とアクションの分離**: ゲームの状態（両プレイヤーのライフ・マナ・各ゾーン・盤面・リーダー・ラウンド数・先手トークン・行動権・連続パス数・乱数の状態）を1つのデータにまとめ、「状態 + アクション → 新しい状態」の関数で進める。
- **合法手の一覧**: 行動権を持つプレイヤーが行える全アクション（カード × マス × 対象 × 強化するか × 支払いの内訳）を列挙する関数を用意する。AIとUIの両方で使う。
- **戦闘だけの計算**: 8章の戦闘を単独で計算する関数を用意する。UIの戦闘結果プレビューとAIの評価に使う。
- **決定性**: シャッフルや「ランダムに」の効果は、試合ごとのシード値から作る乱数で決める。同じシードと同じアクション列なら、必ず同じ結果になるようにする。
- **ログ**: すべてのアクションと、その結果起きた出来事（ダメージ、破壊、移動、成長など）を順番に記録する。リプレイ、デバッグ、テストシナリオに使う。
- **テストシナリオ**: 「初期状態 + アクション列 → 期待する状態」の形で、この仕様書の例（6.2、16.3、17章）を最初のテストケースにする。
