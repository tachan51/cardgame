# 勢力案一覧

> ステータス: ドラフト
> 最終更新: 2026-09-24
> 関連: [企画書](proposal.md) / [ルール仕様書](rules.md)
>
> 試遊版で作る勢力を選ぶための候補一覧。勢力名・リーダー名・能力・数値はすべて仮のもの。
>
> **決定**: 試遊版は **王国騎士団・電脳都市・魔法学院** の3勢力（5章）。野生の密林と中立カードは試遊版の後に回す。

---

## 1. 選び方の基準

試遊版の勢力は、次の基準で選んだ（当初は3勢力の想定で作った基準）。

| # | 基準 | 理由 |
|---|---|---|
| 1 | **盤面の使い方が互いに被らない** | 3勢力で「前列」「後列」「空きマス・破壊」など、盤面の違う部分を担当させると、ルールの面白さを一通り確かめられる |
| 2 | **試遊版のルールだけで作れる** | 挑発・巨体・押し出し・地形は試遊版では使わない（ルール仕様書 19章）。新しいルールが必要な勢力は実装とテストが重くなる |
| 3 | **世界観がはっきり違う** | 「異なる世界の少年が手を組む」というコンセプトを、試遊版の時点で見た目から伝える |
| 4 | **3通りのコンビがどれも成り立つ** | 3勢力なら組み合わせは3通り。どの2人を組ませても、噛み合う戦い方が作れること |
| 5 | **分かりやすい勢力を1つ含む** | 初めて遊ぶ人が基本（前列で守り、空いたレーンを殴る）を覚えられる勢力が必要 |
| 6 | **主なシステムを一通り試せる** | 予備マナ（リーダー能力・強化・起動）、移動、破壊時の効果を、3勢力のどこかで必ず使う |

### 試遊版への向き不向きの記号

| 記号 | 意味 |
|---|---|
| ◎ | 試遊版のルールだけで作れる。実装も軽い |
| ○ | 小さなルールの追加（誘発のタイミングを1つ増やす、など）で作れる |
| △ | 試遊版では使わないルール（巨体・地形など）が必要、またはAIや遊びやすさに課題がある。試遊版の後に回すのがよい |

## 3. 各勢力の詳細

各勢力の「リーダー案」は、能力のコストと成長条件の雰囲気をつかむための例。数値は未調整。

### 1. 王国騎士団 ◎（試遊版）

| 項目 | 内容 |
|---|---|
| 世界観 | 剣と魔法の王国。騎士道を重んじる騎士団と、それを支える僧侶や弓兵 |
| 見た目・名前 | 正統派ファンタジー。紋章、白銀の鎧。カード名は漢字＋カタカナの騎士風（「白銀の盾騎士」「王都の弓兵」） |
| 戦い方 | 体力の高い前列ユニットで壁を作り、「陣形」（左右隣の味方を強化する効果）で横一列を固める。盾で1回の攻撃を防ぐ |
| 主な仕組み | 盾、左右隣への強化、前列ユニットの高体力 |
| 得意 / 苦手 | 正面の殴り合いに強い / 後列を直接狙う貫通・射撃に弱い。動きが遅い |
| リーダー案 | **見習い騎士の少年**。まっすぐで仲間思い。<br>能力「盾の誓い」（3）: 味方1体に盾を与える。<br>成長条件: 味方の盾が合計5回ダメージを防ぐ。<br>成長後: コスト2、対象はこのラウンド中+1/+0 |
| 試遊版 | ◎ 基本ルールをそのまま体現するので、最初に覚える勢力に向く |

### 2. 電脳都市 ◎（試遊版）

| 項目 | 内容 |
|---|---|
| 世界観 | ネオンに照らされた巨大都市。企業の傭兵、ドローン、ハッカー |
| 見た目・名前 | ネオン、ホログラム、黒と蛍光色。カード名はカタカナ・英語風・型番（「警備ドローンMk-II」「ゴーストハッカー」） |
| 戦い方 | 射撃を持つユニットを後列に並べて撃つ。ハッキング（敵ユニットを別のマスへ動かすスペル・能力）で敵の壁をずらし、空いたレーンを作る |
| 主な仕組み | 射撃、敵の移動、起動（ドローンを予備マナで操作） |
| 得意 / 苦手 | 相手の配置を崩すのが得意 / 前列が薄く、正面から押し込まれると弱い |
| リーダー案 | **天才ハッカーの少年**。皮肉屋だが実は寂しがり。<br>能力「強制転送」（3）: 敵ユニット1体を、相手の盤面の空きマスへ動かす。<br>成長条件: 敵ユニットを合計4回動かす。<br>成長後: コスト2、動かしたユニットはこのラウンド攻撃力−2 |
| 試遊版 | ◎ 移動のルールと起動をまとめて試せる。敵を動かす手が増えるぶん、AIの計算は少し重くなる |

### 3. 百鬼夜行 ◎

| 項目 | 内容 |
|---|---|
| 世界観 | 夜だけ現れる妖怪の都。人と怪異の境目があいまいな世界 |
| 見た目・名前 | 墨絵、提灯、和紙の質感。カード名はひらがな・古語・漢字（「からかさ小僧」「朧車」「丑三つの鐘」） |
| 戦い方 | 小さな妖怪を空きマスに次々と湧かせる。倒されると「化けて出る」（破壊時に別の妖怪トークンを出す）ので、盤面が減りにくい |
| 主な仕組み | 破壊時、トークン、空きマスの数を参照する効果 |
| 得意 / 苦手 | 数で押す持久戦、除去への強さ / 1体ずつは弱く、大型ユニットの正面突破に弱い |
| リーダー案 | **妖怪と話せる少年**。飄々として掴みどころがない。<br>能力「百鬼招来」（2）: 自分の空きマスに 1/1 の妖怪トークンを出す。<br>成長条件: 味方ユニットが合計6体破壊される。<br>成長後: トークンが 2/1 になり、破壊されると1回だけ化けて出る |
| 試遊版 | ◎ 破壊時・トークンの処理（ルール仕様書 10.3、11章）を一通り試せる |

| 項目 | 内容 |
|---|---|
| 世界観 | 蒸気機関で動く帝国。歯車、飛行船、からくり兵 |
| 見た目・名前 | 真鍮、歯車、煙。カード名は和製の工業用語風（「蒸気甲冑」「自動砲台」「圧力弁の技師」） |
| 戦い方 | ユニットの多くが起動能力を持つ。カードを少なめに出してマナを残し、予備マナを注いで機械を動かす |
| 主な仕組み | 起動、強化、予備マナが多いほど強くなる効果 |
| 得意 / 苦手 | 中盤以降の爆発力 / 序盤にマナを残すため、盤面を取られやすい |
| リーダー案 | **発明家の少年**。好奇心旺盛で失敗を恐れない。<br>能力「緊急点検」（1）: 味方1体の起動能力を、このラウンドもう1回使えるようにする。<br>成長条件: 起動能力を合計6回使う。<br>成長後: さらにその味方を +1/+1 |
| 試遊版 | ◎ 本作独自の「予備マナ」を最も前面に出す勢力。ただし王国騎士団と同じ西洋風なので、並べると世界観の差が小さくなる |

### 5. 氷海の戦士団 ◎

| 項目 | 内容 |
|---|---|
| 世界観 | 凍てつく海と長い冬の国。ロングシップで海を渡る戦士たち |
| 見た目・名前 | 氷、毛皮、ルーン文字。カード名は力強い和訳風（「斧振りの狂戦士」「霜の吟遊詩人」） |
| 戦い方 | 後列に控えさせ、前列が倒れた瞬間に前進して「突撃」（前進時に強化される効果）する。前進（基本アクション）を最大限に使う |
| 主な仕組み | 移動時（前進時）の効果、前列が破壊されたときの効果 |
| 得意 / 苦手 | 前列が倒されても次が強く出てくる粘り強さ / 後列を先に崩されると何もできない |
| リーダー案 | **族長の息子の少年**。負けず嫌いで声が大きい。<br>能力「角笛」（2）: 後列の味方1体を前進させ、このラウンド +2/+0。<br>成長条件: 味方が合計5回前進する。<br>成長後: +3/+0 になり、前進させたユニットが盾を得る |
| 試遊版 | ◎ 基本アクションの「前進」を主役にできる。電脳都市（後列）と組むと後列の使い方が対照的になる |

### 6. 野生の密林 ◎（試遊版の後）

| 項目 | 内容 |
|---|---|
| 世界観 | 人の手が届かない熱帯の密林。猛獣たちと、獣と共に生きる部族 |
| 見た目・名前 | 濃い緑、極彩色の花、動物の骨、部族の刺青。カード名は動物名と部族の役職（「密林の豹」「部族の呪術師」「太古の大蛇」） |
| 戦い方 | 同じレーンの前列と後列に密林のユニットを並べると、お互いが強化される（群れ）。ラウンド開始時に能力値が育つユニットもいる |
| 主な仕組み | 同じレーンの前後を参照する効果、ラウンド開始時の強化 |
| 得意 / 苦手 | 時間をかけるほど強くなる / 育つ前に除去されると弱い。移動させられると連携が切れる |
| リーダー案 | **獣に育てられた少年**。言葉少なで野性的。<br>能力「雄叫び」（2）: 味方1体を +1/+1。<br>成長条件: 同じレーンの前後に味方が並んだ状態で、戦闘を合計4回終える。<br>成長後: 同じレーンの前後2体とも +1/+1 |
| 試遊版 | ◎ ルール上は作りやすい。電脳都市の「敵を動かす」と相性が悪い（連携を崩される）ので、対戦の駆け引きは生まれる |

### 7. 荒野の保安官 ◎

| 項目 | 内容 |
|---|---|
| 世界観 | 乾いた荒野の開拓地。保安官、ならず者、賞金稼ぎ |
| 見た目・名前 | セピア色、砂ぼこり、手配書。カード名はカタカナ＋二つ名（「早撃ちのジェイク」「酒場の用心棒」） |
| 戦い方 | 先制を持つユニットで、先に撃って相手を倒す。「賞金首」（指定した敵ユニットを倒すと報酬が得られる）で狙いを絞る |
| 主な仕組み | 先制、特定の敵ユニットへの印付け、倒したときの報酬 |
| 得意 / 苦手 | 一対一の撃ち合い / 数の多い相手、盾に弱い |
| リーダー案 | **保安官見習いの少年**。正義感が強いが早とちり。<br>能力「手配書」（1）: 敵ユニット1体に「賞金首」を付ける。賞金首が破壊されたら予備マナ+2。<br>成長条件: 賞金首を3体倒す。<br>成長後: 賞金首を付けた敵はこのラウンド体力−1 |
| 試遊版 | ◎ 先制のルールを主役にできる。射撃・後列寄りの電脳都市とは「撃つ」テーマが少し重なる |

### 8. 終末の街 ◎

| 項目 | 内容 |
|---|---|
| 世界観 | 文明が崩れた後の廃墟。改造車、廃材の武器、生き残りの集団 |
| 見た目・名前 | 錆、ボロ布、スプレーの落書き。カード名は荒っぽいあだ名（「鉄くず拾い」「ガソリン狂い」） |
| 戦い方 | ダメージを受けている間だけ強くなるユニット（ダメージはラウンドをまたいで残る）。自分のライフを払って強い効果を使う |
| 主な仕組み | 「ダメージを受けているなら」の条件、ライフを代償にする効果 |

| リーダー案 | **廃墟育ちの少年**。口は悪いが仲間を見捨てない。<br>能力「燃料投入」（1＋自分のライフ2）: 味方1体を +3/+0。<br>成長条件: 自分のライフが10以下になる。<br>成長後: ライフの代償が1になる |
| 試遊版 | ◎ ルール上は作れる。ただし上級者向けで、最初の3勢力には入れにくい |

### 9. 魔法学院 ◎（試遊版）

| 項目 | 内容 |
|---|---|

| 戦い方 | ユニットは少なめで、スペルを連発する。「強化」（追加コストで威力が上がる）を多く持つ。詠唱してから放つ大魔法（遅延）で相手に対策を強いる。即効の小技でテンポを稼ぐ |

| 必要な追加ルール | 誘発のタイミング「スペル使用時」とキーワード「遅延」「即効」（いずれもルール仕様書で追加済み） |

| 試遊版 | ◎ 遅延の追加で「何を狙うか・どう防ぐか」という盤面の読み合いが生まれ、コンセプトに合う勢力になった |

### 12. 星間艦隊 ◎

| 項目 | 内容 |
|---|---|
| 世界観 | 銀河を航行する艦隊。宇宙軍と機動兵器 |
| 見た目・名前 | 白と青、流線形の艦船、レーダー。カード名は艦名・作戦名（「巡洋艦アルゴ」「軌道爆撃」） |
| 戦い方 | 1レーン全体（前列と後列の両方）にダメージを与える砲撃。次の手番に着弾する遅延攻撃で、相手の配置を縛る |
| 主な仕組み | レーン全体への効果、遅延効果 |
| 必要な追加ルール | なし（遅延はルール仕様書で追加済み） |

## 4. 中立カード

中立カードは、どのデッキにも入れられるカード（ルール仕様書 3.1）。「狭間」に流れ着いたもの・住むものとして描く。**試遊版では作らない**（v0.3 時点の案は cards.md の付録A）。

| 項目 | 方針 |
|---|---|
| 世界観 | 「狭間」の住人、どの世界から来たか分からない漂流者、世界をつなぐ門や道具 |
| 見た目・名前 | 灰色と銀、霧。特定の文化に寄せない（「狭間の番人」「迷い込んだ旅人」「漂流物」） |
| 役割 | 基本的なユニット（キーワードなし、または射撃・盾など単純なもの）、汎用の除去、ドロー、前進の補助 |
| 強さ | 同じコストの勢力カードより少し弱くする。勢力カードを選ぶ理由を残すため |
| 試遊版の枚数 | 12〜16種類 |

## 5. 試遊版の勢力（決定）

### 決定: 王国騎士団 / 電脳都市 / 魔法学院

当初は野生の密林を含む4勢力＋中立カードとしていたが、試遊版では3勢力に絞った。野生の密林と中立カードの案は [cards.md](cards.md) の付録Aに保管している。

| 基準 | 評価 |
|---|---|
| 盤面の使い方 | 前列の壁と戦闘の操作（騎士団）・移動と妨害（電脳）・遅延とスペルの連鎖（学院）で、戦い方がはっきり分かれる |
| 試遊版のルールで作れるか | 3勢力とも ◎（必要な決まりはルール仕様書 v1.7 までで追加済み） |
| 世界観の違い | 中世ファンタジー・近未来SF・学園ファンタジー。騎士団と学院はどちらもファンタジーなので、見た目ははっきり分ける（下記） |
| 分かりやすい勢力 | 王国騎士団が基本を教える役になる |

**騎士団と学院の見た目の分け方**

| | 王国騎士団 | 魔法学院 |
|---|---|---|
| 雰囲気 | 重厚、写実寄りの中世 | 明るい、星空と制服の学園もの |
| 色 | 白銀・紺・深紅 | 夜空の藍・金・パステル |
| カード名 | 漢字中心の騎士風（「白銀の盾騎士」） | 授業・呪文・学園用語（「居残り補習」「学院の修道女」） |

**3通りのコンビ**

| コンビ | 噛み合い方 |
|---|---|
| 騎士団 ＋ 電脳 | 騎士の壁と盾で前列を守り、電脳の移動と妨害で相手の壁を崩す |
| 騎士団 ＋ 学院 | 騎士の壁で時間を稼ぎ、学院のスペルを重ねて終盤の大型カードにつなぐ |
| 電脳 ＋ 学院 | 電脳の移動で敵を遅延の指定マスへ動かして当てる。手札を増やす効果が多く、手数で押す |

**勢力同士の相性（対戦するとき）**

- 電脳の移動・攻撃力ダウンは、前列の壁を頼りにする騎士団に刺さる。
- 学院のマスを指定する遅延は、移動手段の多い電脳には避けられやすく、移動手段の少ない騎士団には当たりやすい。
- 騎士団の「効果で戦闘を起こす」は、ユニットの少ない学院に強い。
