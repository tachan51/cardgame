## 0. このリストの読み方

### 0.1 表の列

| 列 | 意味 |
|---|---|
| ID | カードの識別子。勢力の略号＋番号（KN=王国騎士団、CY=電脳都市、JG=野生の密林、AC=魔法学院、NE=中立、TK=トークン） |
| 種類 | U=ユニット、S=スペル |
| コスト | 通常マナで払うコスト |
| 能力値 | ユニットの「攻撃力/体力」 |
| キーワード | 射撃・貫通・先制・盾・機動・遅延・即効（ルール仕様書 14章） |
| 効果 | カードの効果。強化・起動のコストは予備マナ／通常マナで払う（ルール仕様書 16.2） |

ユニットはすべて、前列・後列のどちらにも置ける（配置制限はない）。

### 0.2 能力語

キーワードではないが、カードの効果をまとめて呼ぶための名前。ルール上の特別な意味はなく、書かれた効果がそのまま適用される（ルール仕様書 11.5）。

| 能力語 | 使う勢力 | 意味 |
|---|---|---|
| 陣形 | 王国騎士団 | 「このユニットの左右隣の味方」に与える常時効果 |
| 群れ | 野生の密林 | 「このユニットと同じレーンのもう一方の列に味方がいる間」だけ有効な常時効果 |

### 0.3 能力値とコストの目安

| コスト | キーワードなしのユニットの能力値合計の目安 |
|---|---|
| 1 | 3（例: 1/2） |
| 2 | 5（例: 2/3） |
| 3 | 7（例: 3/4） |
| 4 | 9（例: 4/5） |
| 5以上 | コスト×2＋1 |

| 要素 | 能力値合計に換算した重さ |
|---|---|
| 射撃・先制・貫通・機動 | 1〜2 |
| **盾** | **3**（1回の攻撃を丸ごと無効にするため重く見る） |
| 常時効果・誘発効果 | 効果の強さに応じて1〜3 |

- 盾を与えるスペル・能力は、最低でも2コスト（即効付きは2コスト、複数に与えるものは4コスト以上）。
- 中立カードは、同じコストの勢力カードより能力値合計を1ほど下げる。

## 9. 調整の観点（テストで見るところ）

| 観点 | 気になる点 |
|---|---|
| 盾の強さ | コストを上げた結果、騎士団の序盤が弱すぎないか。盾の祝福（2コスト即効）の頻度 |
| 高コストの枚数 | 5コスト以上が各勢力5枚＋中立4枚。デッキに入れすぎると序盤に何もできない。AIのデッキでは8〜10枚を目安にする |
| 予備マナの使い道 | 起動・強化が増え、予備マナの使い道の奪い合いになる。リーダー能力と起動のどちらを優先するかの判断が生まれているか |
| 学院のユニット不足 | ユニット9枚で前列を守りきれるか |
| 移動の強さ | システム侵入（2コスト即効）と遅延の組み合わせが強すぎないか |
| 群れの安定性 | 密林は前後を崩されると弱い。電脳との対戦で一方的にならないか |
| 成長条件の達成しやすさ | 各リーダーが試合の中盤（ラウンド5〜7）に成長するくらいを目安に、条件の回数を調整する |
