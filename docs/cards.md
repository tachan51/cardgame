## 0. このリストの読み方

### 0.1 表の列

| 列 | 意味 |
|---|---|
| ID | カードの識別子。勢力の略号＋番号（KN=王国騎士団、CY=電脳都市、AC=魔法学院。付録AのJG=野生の密林、NE=中立） |
| 種類 | U=ユニット、S=スペル |
| コスト | 通常マナで払うコスト |
| 能力値 | ユニットの「攻撃力/体力」 |
| キーワード | 射撃・貫通・先制・盾・機動・遅延・即効（ルール仕様書 14章） |
| 効果 | カードの効果。強化・起動のコストは予備マナ／通常マナで払う（ルール仕様書 16.2） |

ユニットはすべて、前列・後列のどちらにも置ける（配置制限はない）。

### 0.2 表記の決まり

| 表記 | 意味 |
|---|---|
| 「このラウンド中」と書かれていない強化・弱体化 | 永続（ルール仕様書 10.4） |
| 単に「ユニット」と書かれた対象 | 味方・敵のどちらでも選べる。「味方ユニット」「敵ユニット」と書かれていれば、そちらだけ |
| ユニットの移動先 | 特に書かれていなければ、そのユニットの持ち主の盤面の空きマス |
| 「〜を出す」（カードのユニット） | 手札から配置するのではなく、効果で盤面に出す。トークンとして扱う（ルール仕様書 11.7） |
| 「手札に生成する」 | そのカードの新しいコピーを手札に加える（ルール仕様書 11.7） |
| 「使ったスペルの枚数」 | この試合で自分が使ったスペルの累計。生成したスペルも数える |

### 0.3 能力語

キーワードではないが、カードの効果をまとめて呼ぶための名前（ルール仕様書 11.5）。試遊版の3勢力のカードでは使わない（付録Aの野生の密林が「群れ」を使う）。

### 0.4 能力値とコストの目安

| コスト | キーワードなしのユニットの能力値合計の目安（コスト×2＋2） |
|---|---|
| 1 | 4（例: 2/2） |
| 2 | 6（例: 3/3） |
| 3 | 8（例: 4/4） |
| 4 | 10（例: 5/5） |
| 5 | 12（例: 6/6） |
| 6〜10 | 14〜22 |

| 要素 | 能力値合計に換算した重さ |
|---|---|
| 射撃・先制・貫通・機動 | 1〜2 |
| **盾** | **3**（1回の攻撃を丸ごと無効にするため重く見る） |
| 常時効果・誘発効果・起動 | 効果の強さに応じて1〜3 |

- 盾を与えるスペル・能力は、最低でも2コスト（即効付きは2コスト、複数に与えるものは4コスト以上）。
- 手札にある間にコストが下がるカード（CY-21, AC-22）は、下がった後のコストで見て目安に合わせる。

## 1. リーダーについて

リーダーは各勢力の章に記載する。能力のコストは予備マナ／通常マナで払う。各リーダーにつき1ラウンド1回（ルール仕様書 13章）。

## 2. 王国騎士団（KN）

**方針**: 体力の高いユニットと盾で守り、左右隣の味方を強化するユニットで横一列を固める。盾は強いぶんコストが重い。後半は重装の騎士と守護竜で押し切る。

## 6. 調整の観点（テストで見るところ）

| 観点 | 気になる点 |
|---|---|
| 学院のエンジン | 学院の修道女（AC-21）が毎ラウンド魔力還元を生成し、学院長代理（AC-20）がスペル1枚ごとに1枚引き、魔法剣士の先輩（AC-09）は永続で育つ。大賢者の幻影（AC-23）のダメージは終盤15以上になりうる。ノエル成長後（スペル−1）は魔力還元が0コストになる。止まらない連鎖にならないか |
| 繰り返し得られる盾 | 白銀の盾騎士（KN-13）は起動（2）で毎ラウンド自分に盾を得られる（盾を与える効果の目安3より安い）。アルト成長後は+2/+0も付く |
| 竜殺しの英雄 | KN-23（12/2・先制・貫通）は先に倒すので、先制を持つ敵か、戦闘前の除去・スペルでしか止めにくい |
| 電脳の除去 | 直接ダメージは EMPグレネード（4コスト・遅延・2ダメージ）と軌道レーザー照準（3ダメージ）程度。大型ユニットへの対処を移動と攻撃力ダウンで足りるか |
| 衛星兵器の強化 | ラグナロク（CY-25）を強化込みで使うには合計20マナ（通常10＋予備10）が必要。強化なしでは自分のユニットも巻き込む |
| コスト分布 | 電脳は2コストが多く、電脳・学院は7コストがない。騎士団の1コストは1枚 |
| ランダム要素 | 学院にランダム要素が多い（AC-08, 18, 19, 23）。戦闘結果プレビューで結果を予測できない場面が増える |
| 効果で起こす戦闘 | 王国の軍師（KN-17）・聖堂騎士長（KN-22）で行動フェイズ中に戦闘を起こせる。相手に予告（遅延）があるとはいえ、戦闘が1ラウンドに複数回起きる展開が強すぎないか |
| 9・10コスト | 最大マナ10なので、10コストはラウンド10以降でないと出せない（コストが下がるカードを除く）。試合がそこまで続くか |
| 成長条件の達成しやすさ | 各リーダーが試合の中盤（ラウンド5〜7）に成長するくらいを目安に、条件の回数を調整する。アルトは盾で防いだ場合も数えるので、盾が多いデッキでは早く成長しやすい。ノエルは「英知の魔法を使う」が条件なので、スペルの枚数次第で大きくぶれる |
