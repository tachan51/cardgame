## 0. このリストの読み方

### 0.1 表の列

| 列 | 意味 |
|---|---|
| ID | カードの識別子。勢力の略号＋番号（KN=王国騎士団、CY=電脳都市、AC=魔法学院、TK=トークン専用。付録AのJG=野生の密林、NE=中立） |
| 種類 | U=ユニット、S=スペル |
| コスト | 通常マナで払うコスト |
| 能力値 | ユニットの「攻撃力/体力」 |
| キーワード | 射撃・貫通・先制・盾・遊撃・遅延・即効（ルール仕様書 14章） |
| 効果 | カードの効果。強化・起動のコストは予備マナ／通常マナで払う（ルール仕様書 16.2） |

ユニットはすべて、前列・後列のどちらにも置ける（配置制限はない）。

### 0.2 表記の決まり

| 表記 | 意味 |
|---|---|
| 「このラウンド中」と書かれていない強化・弱体化 | 永続（ルール仕様書 10.4） |
| 単に「ユニット」と書かれた対象 | 味方・敵のどちらでも選べる。「味方ユニット」「敵ユニット」と書かれていれば、そちらだけ |
| ユニットの移動先 | 特に書かれていなければ、そのユニットの持ち主の盤面の空きマス |
| 「〜を出す」（カードのユニット） | 手札から配置するのではなく、効果で盤面に出す。トークンとして扱う（ルール仕様書 11.7） |
| 「手札に生成する」 | そのカードの新しいコピーを手札に加える（ルール仕様書 11.7） |
| 「使ったスペルの枚数」 | この試合で自分が使ったスペルの累計。生成したスペルも数える |
| 「〇〇属性」 | カードに付いた分類（例: ドローン属性）。効果で「〇〇属性の」と書かれたときに参照する。属性そのものに効果はない |
| 「〜に変化させる」 | ユニットを、そのマスにいるまま別のカードのユニットに変える。変化前の状態（ダメージ・強化・キーワード・盾・トークンかどうか）はすべてなくなる。移動・配置ではないので、配置時の効果は起きない（ルール仕様書 11.7） |
| 「自分の2勢力のカード」 | 自分のリーダー2人の勢力のカード（トークン専用のカードを除く） |

### 0.3 能力語

キーワードではないが、カードの効果をまとめて呼ぶための名前（ルール仕様書 11.5）。試遊版の3勢力のカードでは使わない（付録Aの野生の密林が「群れ」を使う）。

### 0.4 能力値とコストの目安

| コスト | キーワードなしのユニットの能力値合計の目安（コスト×2＋2） |
|---|---|
| 1 | 4（例: 2/2） |
| 2 | 6（例: 3/3） |
| 3 | 8（例: 4/4） |
| 4 | 10（例: 5/5） |
| 5 | 12（例: 6/6） |
| 6〜10 | 14〜22 |

| 要素 | 能力値合計に換算した重さ |
|---|---|
| 射撃・先制・貫通・遊撃 | 1〜2 |
| **盾** | **3**（1回の攻撃を丸ごと無効にするため重く見る） |
| 常時効果・誘発効果・起動 | 効果の強さに応じて1〜3 |

- 盾を与えるスペル・能力は、最低でも2コスト（即効付きは2コスト、複数に与えるものは4コスト以上）。
- 手札にある間にコストが下がるカード（CY-21, AC-22）は、下がった後のコストで見て目安に合わせる。

## 2. 王国騎士団（KN）

**方針**: 体力の高いユニットと盾で守り、左右隣の味方を強化するユニットで横一列を固める。盾は強いぶんコストが重い。長く残るほど強くなるユニット（近衛弓兵長・スパルタ軍曹の強化）を育て、後半は老将ガラハドの能力値2倍や兵士招集で盤面を固めて押し切る。
