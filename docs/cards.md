## 0. このリストの読み方

### 0.1 表の列

| 列 | 意味 |
|---|---|
| ID | カードの識別子。勢力の略号＋番号（KN=王国騎士団、CY=電脳都市、JG=野生の密林、AC=魔法学院、NE=中立、TK=トークン） |
| 種類 | U=ユニット、S=スペル |
| コスト | 通常マナで払うコスト |
| 能力値 | ユニットの「攻撃力/体力」 |
| キーワード | 射撃・貫通・先制・盾・機動・遅延・即効（ルール仕様書 14章） |
| 効果 | カードの効果。強化・起動のコストは予備マナ／通常マナで払う（ルール仕様書 16.2） |

ユニットはすべて、前列・後列のどちらにも置ける（配置制限はない）。

### 0.2 能力語

キーワードではないが、カードの効果をまとめて呼ぶための名前。ルール上の特別な意味はなく、書かれた効果がそのまま適用される（ルール仕様書 11.5）。

| 能力語 | 使う勢力 | 意味 |
|---|---|---|
| 陣形 | 王国騎士団 | 「このユニットの左右隣の味方」に与える常時効果 |
| 群れ | 野生の密林 | 「このユニットと同じレーンのもう一方の列に味方がいる間」だけ有効な常時効果 |

### 0.3 能力値とコストの目安

| コスト | キーワードなしのユニットの能力値合計の目安（コスト×2＋2） |
|---|---|
| 1 | 4（例: 2/2） |
| 2 | 6（例: 3/3） |
| 3 | 8（例: 4/4） |
| 4 | 10（例: 5/5） |
| 5 | 12（例: 6/6） |
| 6〜10 | 14〜22 |

| 要素 | 能力値合計に換算した重さ |
|---|---|
| 射撃・先制・貫通・機動 | 1〜2 |
| **盾** | **3**（1回の攻撃を丸ごと無効にするため重く見る） |
| 常時効果・誘発効果・起動 | 効果の強さに応じて1〜3 |

- 盾を与えるスペル・能力は、最低でも2コスト（即効付きは2コスト、複数に与えるものは4コスト以上）。
- 中立カードは、同じコストの勢力カードより能力値合計を1ほど下げる。

## 9. 調整の観点（テストで見るところ）

| 観点 | 気になる点 |
|---|---|
| 能力値の底上げ | 目安をコスト×2＋2にしたことで、ユニット同士の殴り合いが強くなり、スペルの除去（3ダメージなど）が相対的に弱くなった。除去の数値が足りているか |
| 9・10コスト | 最大マナ10なので、10コストはラウンド10以降にしか出せない。試合がそこまで続くか（1試合のラウンド数の目安と合わせて確認） |
| 高コストの枚数 | 5コスト以上が各勢力10枚＋中立5枚。デッキに入れすぎると序盤に何もできない。AIのデッキでは10〜12枚を目安にする |
| 盾の強さ | 盾を持つユニットは能力値合計から3を引いているため小さめ。騎士団の序盤が弱すぎないか |
| 全体除去 | 全域ジャミング（CY-22）・流星雨（AC-21）・禁呪（AC-24）・衛星兵器（CY-25）は、密林や騎士団の盤面を一掃しうる。遅延の予告で対策できるか |
| 密林の毒蛇 | 戦闘でダメージを与えた相手を破壊する効果は、大型ユニットに強すぎないか |
| 予備マナの使い道 | 起動・強化が増え、リーダー能力とカードのどちらに予備マナを使うかの判断が生まれているか |
| 成長条件の達成しやすさ | 各リーダーが試合の中盤（ラウンド5〜7）に成長するくらいを目安に、条件の回数を調整する |
