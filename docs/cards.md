## 0. このリストの読み方

### 0.1 表の列

| 列 | 意味 |
|---|---|
| ID | カードの識別子。勢力の略号＋番号（KN=王国騎士団、CY=電脳都市、FO=原初の森、AC=魔法学院、NE=中立、TK=トークン） |
| 種類 | U=ユニット、S=スペル |
| コスト | 通常マナで払うコスト |
| 能力値 | ユニットの「攻撃力/体力」 |
| 配置 | 前=前列のみ、後=後列のみ、空欄=どちらでも |
| キーワード | 射撃・貫通・先制・盾・機動・遅延・即効（ルール仕様書 14章） |
| 効果 | カードの効果。強化・起動のコストは予備マナ／通常マナで払う（ルール仕様書 16.2） |

### 0.2 能力語

キーワードではないが、カードの効果をまとめて呼ぶための名前。ルール上の特別な意味はなく、書かれた効果がそのまま適用される（ルール仕様書 11.5）。

| 能力語 | 使う勢力 | 意味 |
|---|---|---|
| 陣形 | 王国騎士団 | 「このユニットの左右隣の味方」に与える常時効果 |
| 群れ | 原初の森 | 「このユニットと同じレーンのもう一方の列に味方がいる間」だけ有効な常時効果 |

### 0.3 能力値の目安

| コスト | キーワードなしのユニットの能力値合計の目安 |
|---|---|
| 1 | 3（例: 1/2） |
| 2 | 5（例: 2/3） |
| 3 | 7（例: 3/4） |
| 4 | 9（例: 4/5） |
| 5以上 | コスト×2＋1 |

- キーワード1つ、または効果1つにつき、能力値合計を1〜2下げる。
- 配置制限（前・後）があるユニットは、合計を少し上げてよい。
- 中立カードは同じコストの勢力カードより合計を1ほど下げる。

## 9. 調整の観点（テストで見るところ）

| 観点 | 気になる点 |
|---|---|
| 学院のユニット不足 | ユニット8枚で前列を守りきれるか。石像（AC-06）と石の番兵（TK-03）で足りなければ、中立ユニットで補う前提でよいか |
| 移動の強さ | 電脳のシステム侵入（CY-14、2マナ即効）は、遅延（AC-14 など）と組むと確実に当たる。強すぎればコストを上げるか即効を外す |
| 群れの安定性 | 森は前後を崩されると弱い。電脳との対戦で一方的にならないか |
| 盾の多さ | 騎士団の盾が多く、ダメージの小さい相手（電脳のドローン、学院の魔力の矢）が何もできなくならないか |
| 遅延の除去 | 審判の槌（KN-20）・崩落の予言（AC-14）・軌道レーザー照準（CY-19）が、対策されにくい状況で強すぎないか |
| 予備マナ | 魔力還元（AC-19）と境界の見張り（NE-07）で予備マナが貯まりすぎないか。リーダー能力が毎ラウンド2回使えてしまう展開にならないか |
| 成長条件の達成しやすさ | 各リーダーが試合の中盤（ラウンド5〜7）に成長するくらいを目安に、条件の回数を調整する |
