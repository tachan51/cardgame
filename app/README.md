# AI 対戦の試遊版（M2）

ルールエンジン（[engine/](../engine)）を使って、見本デッキで AI と対戦する画面。
公開先: GitHub Pages のルート（https://tachan51.github.io/cardgame/）。

## 動かし方

```sh
cd app
npm install
npm run dev     # http://localhost:5173
npm test        # 操作の組み立てのテスト
npm run build   # 型チェックと dist/ への書き出し
```

## できること

| タスク | 内容 |
|---|---|
| 2-1 対戦画面 | 盤面（4レーン×前後×2人）、手札、ライフ、通常マナ（◆）と予備マナ（◇）、リーダー（成長条件の進み具合・能力のコスト・使用済み）、予約中の遅延効果の印（⏳） |
| 2-2 操作 | 手札のカードを選ぶ → 強化するか → マス・対象を選ぶ → 予備マナと通常マナの内訳を選ぶ。自分のユニットを選ぶと前進・機動・起動。リーダー能力の「使う」、パス |
| 2-3 戦闘の予測 | 「このまま戦闘になったら」のライフの変化と、破壊されるユニット（☠）・受けるダメージを常に表示する（予約中の遅延効果が発動した後の予測） |
| 2-4 AI の手を1手ずつ見せる | AI は1手ごとに少し間をあけて行動し、「直前の出来事」とログに何をしたかを表示する |
| 2-5 ルールベースの AI | `engine/src/ai.ts`。公開情報だけを使い、合法手を1つずつ試して、戦闘の結果まで見た評価が一番高い手を選ぶ |
| 2-6 開始から終了まで | デッキ（見本デッキ）を選ぶ → マリガン → 対戦 → 結果。途中の試合はブラウザに保存され、「前回の続きから」で再開できる |

## 構成

| ファイル | 内容 |
|---|---|
| `src/data.ts` | カードデータと見本デッキの読み込み（`data/` を JS に組み込む） |
| `src/game.ts` | 試合の進行（人間の操作の適用、AI の手番、保存） |
| `src/select.ts` | 操作の組み立て。合法手の一覧を、クリックで選んだ内容に合うものへ絞り込む |
| `src/text.ts` | ログの文章・キーワード名などの表示用の文字 |
| `src/ui/setup.ts` | デッキ選び |
| `src/ui/battle.ts` | 対戦画面（マリガン・選択・結果を含む） |
